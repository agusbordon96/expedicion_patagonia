# 🦴 Expedición Patagonia

**Expedición Patagonia** es un videojuego 2D desarrollado con JavaScript y p5.js, inspirado en el trabajo arqueológico y paleontológico de la Patagonia argentina.

## 🎮 ¿De qué trata?

El jugador se convierte en parte de una expedición que debe explorar un yacimiento, excavar y recolectar huesos fósiles para trasladarlos al museo. Allí, los restos se utilizan para completar esqueletos y contribuir a las exposiciones.

## 🎯 Objetivo del juego

- Explorar el yacimiento y encontrar huesos.
- Recolectar y transportar fósiles teniendo en cuenta la capacidad del inventario.
- Llevar los hallazgos al museo para completar esqueletos.
- Administrar el tiempo disponible y avanzar en la expedición.

## 🛠️ Tecnologías utilizadas

- **HTML5** para la estructura del juego.
- **JavaScript** para la lógica y las mecánicas.
- **p5.js** para los gráficos y la interacción.
- **p5.sound** para los efectos de sonido.

## 🌎 Propósito

El proyecto busca combinar entretenimiento, exploración y una aproximación lúdica al patrimonio paleontológico de la Patagonia, convirtiendo el proceso de búsqueda y reconstrucción de fósiles en una experiencia interactiva.
